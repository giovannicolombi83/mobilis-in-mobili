# Mobilis in Mobili — Captain Nemo: A Journey Within

App per telefono e computer del prototipo di **Mobilis in Mobili** (Gallinello Games · game design di Giovanni Colombi, art di Sam Ristola).

- Gioca: https://giovannicolombi83.github.io/mobilis-in-mobili/
- Modalità: contro AI (2–3 giocatori), 4 a squadre, solitario contro la Nemesis
- Italiano e inglese; installabile come app (PWA), funziona anche offline

Prototipo di playtest: regole dal regolamento del 30 ottobre 2026.
